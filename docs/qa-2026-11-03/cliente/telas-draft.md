# Telas — o que melhorar (visão de primeiro acesso, persona cliente)

- **Onboarding (app/index.tsx)**: marca "Judeu" + tagline "Ajuda + eu" → duas identidades; "Quero contratar · Prestadores perto de você" promete uma lista de prestadores que a home não tem (explore oculta, provider/[id] sem entrada). Sugestão: um nome só; subtítulo "Peça ajuda perto de você".
- **Cadastro (signup.tsx)**: e-mail sem validação local (vai para "Dados inválidos" da API); sem olho na senha; sem link "já tenho conta"; vindo de "Criar conta" do login o papel é CLIENT sem o usuário saber. Erro de termos aparece só após tocar em Criar conta (ok).
- **Login (login.tsx)**: botões Google/Apple são `View` sem ação (UI morta); "Esqueci minha senha" leva a um fluxo cujo código é fixo (C-01).
- **Home (tabs/index.tsx)**: tab bar escondida — Chamadas/Perfil só via avatar; pill "Sua localização" mostra o endereço padrão (não a localização); sem endereço mostra "Definir endereço"; card "Pronto para ajudar? / Quero atender" aparece para um cliente novo (confunde: ele veio contratar); mapa vazio sem prestadores; única ação é "Precisa de ajuda?". Sugestão: mostrar tab bar, lista/pins de prestadores, separar "atender" num onboarding próprio.
- **Pedir ajuda (create-order.tsx, aberta)**: não escolhe endereço (usa o padrão em silêncio; sem endereço → erro da API "Cadastre um endereço no perfil" sem atalho); não mostra categoria; "Total com taxa" sem explicar 8%; "Prefere explicar conversando?" leva a JudIA que precisa de dev build. Chamada direta: "Serviço a combinar" quando o prestador não tem catálogo e total exibido ≠ R$ 0 gravado (C-06); data/hora digitadas livres (DD/MM/AAAA, HH:MM) sem picker.
- **Espera (waiting/[id].tsx)**: cronômetro em segundos crus ("10860s") e errado por fuso (C-05); ajuda aberta sem expiração visível; "Essa pessoa não respondeu" oferece "próxima perto" com preço que a API ignora; X leva à home (não há "ver detalhes").
- **Pagamento (payment/[id].tsx)**: sem nome do prestador/serviço; sem gate de status (abre em CREATED/cancelado); "Dinheiro no local" vira toast "Pagamento em dinheiro confirmado" (nada foi pago); CARD exige Stripe PaymentSheet; PIX "Fique nesta tela".
- **Detalhe do pedido (order-detail-client.tsx)**: "Cancelar pedido" sem confirmação; "Ir para pagamento" visível antes do aceite; timeline "Concluído e pago" mesmo com CASH pendente; "★ 0.0" para prestador novo; header "Pedido #abc123".
- **Tracking (tracking/[id].tsx)**: "Calculando chegada..." eterno sem localização; AWAITING_CONFIRMATION cai no texto "Aguardando prestador"; passo "Chegou" para IN_PROGRESS.
- **Chat (order-chat.tsx + chat-price-panel.tsx)**: sem horário nem "lido"; botão "+" sem função; input ativo em pedido cancelado/concluído; "Cancelar" (recusar proposta) soa como cancelar o pedido; "Ajustar valor" sempre falha (C-03).
- **Proposta (propose-form.tsx)**: rótulos "Prestador/Cliente" (vocabulário diferente de "quem ajuda"); histórico sem data.
- **Avaliação (rating-form.tsx)**: "Serviço concluído!" aparece também para pedido cancelado (C-12); tags viram texto "Pontual · Caprichoso — comentário"; "Voltar aos pedidos" vs aba "Chamadas".
- **Chamadas (orders.tsx)**: cancelados dentro de "Concluídos" e abrem avaliação; horários errados por fuso; vazio "Nenhum pedido no histórico ainda" vs título "Minhas chamadas".
- **Perfil (profile.tsx)**: "Sair da conta" sem confirmação; toggle "Atender ajudas" para cliente zerado; "Membro desde 2026"; sem entrada para Notificações (só sino na home); sem "Vagas" para cliente (API permite candidatar).
- **Suporte (support*.tsx)**: criar chamado → 500 (C-02); lista/pós-criação navegam sem id (C-08); FAQ ok.
- **Notificações (notifications.tsx)**: filtros "Pedidos/Mensagens" (sem Suporte/Vagas); todo "order" abre Pagamento (C-11); horários por fuso.
- **Endereços (addresses.tsx / address-form.tsx)**: "Tornar padrão" → 500 (C-04); form manda GPS do aparelho como coordenada do endereço (C-09); CEP via ViaCEP ok; cidade/UF já vêm "Palmas/TO" (bom); sem mapa para confirmar o pino.
- **JudIA (ai/chat.tsx)**: no dev client sem ExecuTorch mostra "precisa de um build de desenvolvimento" e manda "Escolher no mapa" — mapa sem prestadores.
