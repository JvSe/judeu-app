## Confusões de regra (sem ser bug)
- Chamada direta: pagamento vem antes de qualquer contato; "Dinheiro no local" é tratado como pago (toast "Pagamento em dinheiro confirmado").
- Ajuda aberta: UI exige "Agendar" para negociar com profissional (create-order.tsx canNegotiate = scheduled && allowsNegotiation) — a API permite em qualquer CREATED.
- Ajuda aberta não tem expiração visível (servidor para de exibir após 4 h; cliente espera para sempre).
- Vocabulário: Pedido / Chamada / Ajuda / Solicitação / Serviço misturados (header "Pedido #abc123", tab "Chamadas", botão "Cancelar pedido", timeline "Concluído e pago").
- Prestador recebe pedido de Frete sendo eletricista; cliente não escolhe quem atende a ajuda aberta.
- Taxa de 8% aparece só no total ("Total com taxa") sem explicação.
